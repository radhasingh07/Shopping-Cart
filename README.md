# 🛒 Shopping Cart Dashboard

A responsive Shopping Cart Dashboard built using HTML, CSS, and JavaScript. The application provides a clean and interactive interface for managing products in a shopping cart, updating quantities, calculating totals, and improving the online shopping experience.

## ✨ Features

- Add products to the shopping cart
- Increase or decrease product quantity
- Remove items from the cart
- Automatic total price calculation
- Responsive design for desktop and mobile devices
- Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
Shopping-Cart/
│── index.html
│── style.css
│── script.js
│── images/
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
